# Ant IAM 项目简报

## 功能特点

- **统一目录**：组织树、用户、用户组、身份源集中维护，支持从钉钉、飞书、企业微信定时或实时同步，也支持 JSON 导入。
- **账号生命周期**：激活、停用、锁定、离职四个标准动作，停用、锁定与离职会自动停用直接应用授权、结束活跃会话并撤销活跃令牌。
- **多种登录方式**：用户名密码、短信快捷登录，以及微信、QQ、钉钉、飞书、企业微信、GitHub、Gitee、支付宝等第三方登录。
- **多因子认证**：TOTP、短信、邮件、WebAuthn、恢复码五类因子，支持因子注册、启停与恢复码生成。
- **认证策略**：可配置 MFA 要求、注册引导、二次认证、拒绝登录、密码最小长度、失败锁定、密码过期与密码历史。
- **单点登录**：对外提供 OIDC / OAuth2、SAML 2.0、CAS 三种协议，客户端支持 PKCE、刷新令牌轮换、同意管理与令牌撤销。
- **应用管理**：应用增删改与启停、应用分组、SSO 参数配置、ID token 声明策略。
- **访问授权**：权限 → 角色 → 用户组 / 用户的 RBAC 模型，应用授权支持设置有效期。
- **访问决策与影响面分析**：可查"某用户为什么能访问某应用"，也可查"改动某权限或角色会影响哪些人"。
- **权限自助**：用户对可申请应用发起访问申请，管理员审批后自动生成授权。
- **通讯录同步接口**：SCIM 2.0 提供用户、用户组、组织的读写接口与发现能力。
- **风险控制**：基于 IP、User-Agent、失败登录次数、设备指纹、地理位置的登录风险规则，输出低/中/高三级风险。
- **审计与运营**：认证事件、会话记录、管理操作全程留痕，支持关键字检索与 CSV 导出；仪表盘展示认证趋势、应用访问排名、认证方式与登录地点分布。
- **在线会话管理**：查看有效会话并支持强制下线。
- **多租户**：用户、应用、身份源等资源按租户隔离，支持租户级设置。
- **配套能力**：邮件与短信通道、阿里云 OSS / 腾讯 COS / 七牛 Kodo / S3 兼容存储适配、IP 地理库解析、OpenAPI 与 Swagger UI 交互文档。

详细说明见 `docs/project-overview.md`，接入步骤见 `docs/integration-guide.md`。
