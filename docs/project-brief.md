# IAM 项目简报

## 功能特点

- **统一目录**：组织树、用户、用户组、身份源集中维护，支持从钉钉、飞书、企业微信定时或实时同步，也支持 JSON 导入。
- **账号生命周期**：激活、停用、锁定、离职四个标准动作，停用、锁定与离职会自动停用直接应用授权、结束活跃会话并撤销活跃令牌。
- **多种登录方式**：用户名密码、短信快捷登录，以及微信、QQ、钉钉、飞书、企业微信等第三方登录。
- **多因子认证**：TOTP、短信、邮件、WebAuthn（原型）、恢复码五类因子，支持因子注册、启停与恢复码生成，验证码不回传明文。
- **认证策略与安全设置**：可配置 MFA 要求、注册引导、二次认证、拒绝登录；密码策略覆盖长度、复杂度、个人信息、弱密码、连续字符、键盘序列、历史密码与过期提醒；会话有效期、“记住我”、并发会话数、失败锁定与自动解锁、CSP 均可在线调整并即时生效。
- **单点登录**：对外提供 OIDC / OAuth2、SAML 2.0（断言签名）、CAS、JWT 四种协议，客户端支持 PKCE、刷新令牌轮换、同意管理与令牌撤销；签发前校验应用访问授权。
- **应用管理**：应用增删改与启停、应用分组、SSO 参数配置、ID token 声明策略、客户端密钥重置。
- **访问授权**：权限 → 角色 → 用户组 / 用户的 RBAC 模型；应用可设为手动授权或全员可访问，授权对象支持用户、用户组和组织（下级组织继承），支持批量授权与有效期。
- **访问决策与影响面分析**：可查"某用户为什么能访问某应用"，也可查"改动某权限或角色会影响哪些人"。
- **权限自助**：用户对可申请应用发起访问申请，管理员审批后自动生成授权。
- **通讯录同步接口**：SCIM 2.0 提供用户、用户组、组织的增删改查（含 PATCH）、组合过滤与发现能力。
- **风险控制**：基于 IP、User-Agent、失败登录次数、设备指纹、地理位置的风险规则，输出低/中/高三级风险；登录时高风险拒绝、中风险要求 MFA（设备指纹与地理位置规则暂未接入登录链路）。
- **审计与运营**：认证事件、会话记录、管理操作全程留痕并记录客户端 IP 与 User-Agent，支持关键字检索与 CSV 导出；仪表盘展示认证趋势、应用访问排名、认证方式与登录地点分布。
- **在线会话管理**：查看有效会话并支持强制下线。
- **控制台分级管理**：按模块细分只读 / 可写权限点，写操作防提权，菜单按权限裁剪。
- **多租户**：用户、应用、身份源等资源带租户归属，支持租户级设置（控制台按租户隔离数据尚在规划）。
- **配套能力**：邮件与短信通道（可发送测试）、阿里云 OSS / 腾讯 COS / 七牛 Kodo / S3 兼容存储适配（可在线校验）、用户头像、IP 地理库解析与在线更新、OpenAPI 与 Swagger UI 交互文档。
